# Model Card 规范（AI Studio 无代码微调）

AI Studio 无代码微调工具在训练完成后，用本规范生成衍生模型的 Model Card（README.md）。

---

## 核心原则

1. **仅展示可验证字段**：只能展示从任务配置、训练日志、模型元数据、数据集元数据中确定存在的字段。无法获取或无法验证的字段，不得编造，不得用示例值替代。
2. **缺失字段直接省略**：任何字段若无法从真实来源获取，对应的整行、整句或整节直接省略，不显示"暂无""未知""未自动获取"等占位文本。
3. **评估指标必须有真实来源**：不得展示未真实计算的 BLEU、ROUGE、准确率等指标。无自动评估时，整节改写为说明，不展示指标表格。
4. **协议声明必须可溯源**：开源协议、商业使用许可只能来自基座模型元数据或官方标注，无来源则整行省略。
5. **高风险领域自动追加专项声明**：医疗、法律、金融、招聘等场景在局限性章节强制追加对应声明，不可折叠。

## 一、模型命名

### 格式

```
【{基座模型名称}】{场景/功能描述}
```

### 基座模型名称

取自用户选择的基座模型版本号，方括号包裹。

| 基座模型 | 标题前缀 |
|---------|---------|
| ERNIE-4.5-0.3B | `【ERNIE-4.5-0.3B】` |
| ERNIE-4.5-21B-A3B | `【ERNIE-4.5-21B-A3B】` |
| ERNIE-4.5-Turbo | `【ERNIE-4.5-Turbo】` |

### 场景/功能描述

根据任务类型与数据集信息自动生成，12 汉字以内，单一职责。

**生成优先级**：

1. 依次从数据集名称、数据集 README、数据集仓库名、训练任务名、数据字段名、样例 prompt 中提取领域/任务关键词，结合任务类型后缀生成描述。
2. 以上均无法识别关键词时，弹出文本输入框，预填默认建议，让用户一句话描述微调目标，基于该输入生成。
3. 用户跳过交互时，回退为"自定义 + 任务类型"兜底（见下表）。

**任务类型映射**：

| 任务类型 | 后缀规则 | 用户跳过兜底 |
|---------|---------|-----------|
| 对话/问答 | 场景词 + `助手` 或 `顾问` | `自定义问答助手` |
| 文本生成 | 场景词 + `生成器` | `自定义文本生成模型` |
| 文本分类/情感分析 | 场景词 + `分类模型` | `自定义文本分类模型` |
| 信息抽取/序列标注 | 场景词 + `提取器` | `自定义信息提取模型` |
| 评分/回归 | 场景词 + `评分模型` | `自定义评分预测模型` |
| 翻译 | `{语言对}翻译模型` | `自定义翻译模型` |

**禁用词**：标题禁止使用"专家级""权威""诊断""判决""保证准确""精准预测""治愈""治疗方案""法律判决""投资建议"等夸大或高风险表达；数据集名称含禁用词时自动替换为中性表达。

框架版本（PaddlePaddle / PyTorch）不在标题中体现，写入微调信息章节。

## 二、各章节内容规范

以下所有字段均遵循"缺失即省略"原则。

### 2.1 模型介绍

模板：
> 【{基座模型名称}】{场景/功能描述} 是基于 {基座模型全称} 进行监督微调的衍生模型。该模型通过在 {数据集名称} 上进行监督微调（Supervised Fine-Tuning），针对 {目标场景/任务} 进行了专项优化。

| 字段 | 来源 | 缺失处理 |
|-----|------|---------|
| 基座模型全称 | 系统记录 | 必可获取 |
| 数据集名称 | 用户上传记录 | 必可获取 |
| 目标场景/任务 | 任务类型 + 关键词组合 | 无法提取关键词时使用"用户自定义{任务类型}任务" |

### 2.2 模型描述

模板：
> **模型结构**：本模型基于 {基座模型架构}，属于 {ERNIE版本系列}，采用 {架构类型} 架构。基座模型参数量为 {参数量}。
> **微调方式**：采用监督微调（SFT）方式，在 {数据集名称} 上进行 {训练轮数} 个 epoch 的训练。
> **适用任务**：{自动生成的任务场景列表}。

| 字段 | 来源 | 缺失处理 |
|-----|------|---------|
| 基座模型架构 | 基座模型元数据 | 省略"基于 XX 架构"分句 |
| ERNIE版本系列 | 基座模型元数据 | 省略"属于 XX 系列"分句 |
| 架构类型 | 基座模型元数据或白名单 | 省略"采用 XX 架构"分句 |
| 参数量 | 基座模型元数据 | 省略"参数量为 XX"分句 |
| 训练轮数 | 训练配置/日志 | 改写为"采用监督微调（SFT）方式在 {数据集名称} 上训练。" |
| 适用任务 | 任务类型 + 关键词扩展 | 兜底"{任务类型}任务" |

> - 输入类型：文本，建议单次输入不超过 {上下文窗口} tokens
> - 输出类型：{根据任务类型推断}
> - 语言：{根据数据集推断}

| 字段 | 来源 | 缺失处理 |
|-----|------|---------|
| 目标使用场景描述 | 任务类型 + 场景关键词 | 无法提取时写"用户自定义{任务类型}场景" |
| 上下文窗口 | 基座模型配置元数据 | 省略"建议单次输入不超过 XX tokens"分句 |
| 输出类型 | 任务类型推断 | 必可推断 |
